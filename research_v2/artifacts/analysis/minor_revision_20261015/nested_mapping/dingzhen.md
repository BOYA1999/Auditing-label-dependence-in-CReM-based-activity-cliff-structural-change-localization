This directory contains two post-confirmation sensitivities of the existing CReM-mean study. Frozen scores, models, neighborhoods, pairs and prior outputs are unchanged. It does not concern drug_design_20261015. Implementation: research_v2/scripts/analyze_minor_nested_mapping.py.

## Fixed protocol, written before calculation

- R5: 617 eligible boundary-extended pairs, 27 confirmation datasets, six representation/predictor configurations, three seeds and both label conditions. For each pair and Monte Carlo draw, independently randomize labels uniformly within each endpoint, preserving its observed positive count. Share those labels across every configuration, seed and condition. Hold atom scores and endpoint-exact AP expectations fixed. Compute tie-grouped AP per seed, average seeds within condition, difference trained minus permuted, take the median over component/configuration rows within dataset, then the median across datasets. Calculate raw nAP and endpoint-exact-adjusted nAP. Use 2,000 Monte Carlo draws, seed 20261015 with SHA-256-derived pair streams. Report the full-statistic reference mean, median, 2.5–97.5 percentiles, corrected empirical tail fractions, Monte Carlo standard errors, bootstrap uncertainty of the reference median, and split-half centers. This is conditional on frozen scores and endpoint positive counts, not a model-label exchangeability test or a population confidence interval.
- R6: inspect the existing 77 ambiguous pairs among the 611 natively reproduced stored mappings. Enumerate the same query-compatible endpoint atom sets with a maximum of 256 matches per endpoint; do not append missing chosen mappings. Verify boundary-label invariance for duplicate query matches of the same atom set. Derive strict-unmatched and boundary-extended labels from each common atom/bond mapping. For each candidate, use the identical label vector for trained and permuted conditions and all three seeds; calculate AP before seed averaging. Preserve the six unreproduced mappings as stored in the full-population result. Invalid all-positive/all-negative candidates must be recorded explicitly and excluded from the corresponding evaluable sensitivity only.
- Propagate mapping alternatives through the same primary aggregation. Report stored mapping, lexicographically first candidate, per-pair candidate minimizing/maximizing the median paired contrast across the fixed six configurations, and 2,000 uniformly sampled candidate assignments shared across all configurations/conditions/seeds. Report component/configuration-wise extreme envelopes separately as conservative bounds that need not correspond to one jointly attainable mapping assignment. Mapping assignment percentiles are sensitivity ranges, not confidence intervals.
- Validation: reproduce observed frozen row metrics and primary point estimates; check vectorized AP against the established grouped AP function; reproduce 77 ambiguous pairs and prior candidate counts; verify stored boundary labels against candidate reconstruction; preserve input and output hashes in machine-readable provenance. Stop after these two sensitivities and report all null, negative or discordant results.

## Protocol amendment before any completed result

The first run stopped on an explicit stored-label validation assertion for CHEMBL204_Ki, component 20: the representative query embedding for the stored right atom set gave boundary atom 60 instead of stored atom 59 (concatenated pair indices). Thus atom-set identity does not in general identify the common bonds or boundary labels. No result from that failed run is reported as evidence. R6 now enumerates all query embeddings (uniquify=False, at most 4,096 per endpoint, with an explicit truncation assertion), retains unique (matched atom set, boundary set) options, and deduplicates identical pair label vectors separately for each rationale. It verifies that the original unique atom sets and the stored boundary labels are recovered. This changes no scores or main labels. The sensitivity remains restricted to the existing 77 atom-set-ambiguous pairs; it does not claim exhaustive detection of bond ambiguity in the other pairs. Candidate assignments are uniform over distinct evaluable label vectors, not over redundant symmetry embeddings.
