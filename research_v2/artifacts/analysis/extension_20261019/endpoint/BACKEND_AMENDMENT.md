# Inference-backend amendment — 2026-10-19

This amendment was fixed after the first export replay failure and before computing the new crossed aggregate, structural reference, bootstrap intervals or noise-normalized outcomes. It changes inference consistency for the new analysis, not the saved training contracts, models, historical atom scores or historical estimates.

The export failed on CHEMBL1862_Ki / MoLFormer / XGBoost, initialization 42, permutation 43, component 10: CPU reload produced raw nAP 0.1664942103966494, while the source scoring record was 0.1586142854435537. The historical permutation runner evaluated newly fitted XGBoost units directly with the training object's CUDA device; reused original units were loaded with the original prediction helper's default CPU setting. Restoring the source-specific device reproduced the failed record. Exact rank/tie scoring makes this an analytically meaningful replay difference, even when underlying prediction or atom-score differences are small.

The new crossed analysis will therefore use uniform CPU inference for every XGBoost model, including all observed-label and permutation/initialization combinations. MLP uses its existing GPU inference contract. Observed-label scores are reconstructed from the saved models with those same backends rather than using rounded/parsed CSV scores; the original observed CSV arrays remain in the source-compatible sensitivity. This also exposes any exact-tie effects of serialization separately from inference-device effects. This is fixed from implementation evidence before seeing the new aggregate result, with no outcome-based device selection, model refit, score rounding, epsilon, tie merging or gate relaxation.

Source-compatible predictions remain a separate reconstruction and sensitivity. Their pair scores must continue to reproduce the historical saved rows. Exports preserve both source-compatible and uniform-CPU permuted XGBoost atom arrays. Main raw and endpoint-exact crossed estimates, 2,000 complete-statistic structural-reference draws and uncertainty resampling use uniform-CPU XGBoost scores. Source-compatible raw and endpoint-exact point estimates and pair/configuration effects are reported as backend sensitivity without a second full Monte Carlo campaign. The primary observation/label-permutation pairing and all endpoint counts, labels, neighborhoods, configurations and aggregation levels stay fixed.

Historical 617/611 results and S43/S44 remain unchanged. New uniform inference is saved-model reanalysis and is not counted as newly trained evidence. The crossed model task separately records the number of missing heads actually fitted. The source-compatible replay gate and the scientific backend sensitivity answer different questions and will be reported separately.
